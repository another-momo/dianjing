# 非文字元素分离 Prompt 模板

阶段 1 `generate_image` 每项 request 的 prompt 字段填法。分两种：**主体/前景等普通层**用透明变体（`transparent_background: true`，目标之外全透明）；**背景层**用补全变体（`transparent_background: false`，输出完整不透明底图）。

---

## 1. 透明变体（背景以外的所有层）

```
任务：原位隔离重绘当前目标，供后续分层重组。

目标名称：<中文内容名>
包含范围：<目标及不可分割的装饰>
排除范围：<其他主体、背景、独立图标及普通文字>
整幅画布：<W> × <H> 像素
原图中的外接范围：左上角 (<x>, <y>)，宽 <width>，高 <height> 像素
视觉中心与关键锚点：<中心位置、底部接触点等>

仅保留这个目标，其余区域透明。保留目标内部真实的白色和浅色细节。
输出原图同尺寸的整幅画布；不要把目标移到画布中心、放大填满、截成小图或重新排版。
```

### 字段填写规则

- **目标名称**：阶段 0 起的语义名（主体 / 前景 / Logo / …）的中文描述
- **包含范围**：目标本体 + 与之视觉绑定不可分割的装饰（如阴影、光晕、内嵌细节）。问自己"如果去掉这部分，目标就不完整了吗？"——是则包含，否则排除
- **排除范围**：本次要拆的其他层（背景 / 主体 / 前景 / Logo / 文字等）——**逐项点名**，不要写"等等"
- **整幅画布**：原图宽高，与 `width` / `height` 参数对齐
- **外接范围**：目标在原图中的 bounding box——`look` 截图视觉估算（原图是一张位图，内部元素没有节点元数据可读）
- **视觉中心与锚点**：目标内的关键像素位置（如人物的眼睛、产品 logo 的中心、底部接触点），帮助生图模型保持姿态 / 比例
- **最后两句**：原文照抄。明确"其余区域透明"+"原图同尺寸整幅画布"是核心约束

---

## 2. 补全变体（背景层专用）

背景层的目标不是"抠出来"，而是**把主体 / 文字 / Logo 等抹除后补全成完整底图**——透明输出会把被遮挡区留成空洞，所以背景层必须 `transparent_background: false`、不透明整幅输出：

```
任务：原位完整重绘底图，供后续分层重组。

目标：完整背景——<背景内容描述（如"深蓝到紫色径向渐变 + 散布星点"）>
抹除并补全：<主体、文字行、Logo、按钮等，逐项点名>
整幅画布：<W> × <H> 像素，不透明输出

输出完整、连续、无破洞的底图。被抹除元素占据的区域按周围背景内容自然补全；
不要保留任何被抹除元素的轮廓或残影；不要截小、留白边或重新排版。
```

---

## 3. request 完整字段（与 prompt 配合）

```typescript
{
  prompt: '<按上述模板填——背景层用补全变体，其余层用透明变体>',
  references: [sourceNodeId],         // 原图节点 ID
  replace_id: prebuiltFrameId,        // 该层预建 Frame 的 ID——原地换 fill
  transparent_background: false,      // 背景层 false（完整底图）；其余层 true（透明 PNG）
  width: 原图W,                       // = prompt 整幅画布宽
  height: 原图H,                      // = prompt 整幅画布高
  quality: 'high',
  output_format: 'png'
}
```

注：请求尺寸会被 API 约束归一（16px 对齐 + 像素总量上下限 + 纵横比钳制），返回可能标注尺寸微调——生成结果仍以 FILL 模式铺满预建 Frame，无需处理。

## 4. 填充示例

### 示例 1：产品海报背景层（补全变体）

```
任务：原位完整重绘底图，供后续分层重组。

目标：完整背景——深蓝到紫色径向渐变 + 散布小星点
抹除并补全：中央产品图、底部 Logo、标题文字行、按钮
整幅画布：1080 × 1350 像素，不透明输出

输出完整、连续、无破洞的底图。被抹除元素占据的区域按周围渐变与星点分布自然补全；
不要保留任何被抹除元素的轮廓或残影；不要截小、留白边或重新排版。
```

```

整幅画布：800 × 800 像素

视觉中心与关键锚点：耳机中心 (400, 440)；左耳罩 (260, 480)、右耳罩 (540, 480)

仅保留这个目标，其余区域透明。保留目标内部真实的白色和浅色细节。
```

## 5. 常见 prompt 失误

| 失误 | 后果 | 修正 |
|---|---|---|
| 透明变体不写"其余区域透明" | 生图模型填上白 / 黑底 | 必须含原句 |
| 不写"原图同尺寸整幅画布" | 模型截成小图 / 居中放大 | 必须含原句 |
| 背景层套用透明变体 | 被主体遮挡区变透明空洞 | 背景层用补全变体 + `transparent_background: false` |
| 补全变体不逐项点名抹除对象 | 主体残影留在底图上 | 抹除清单逐项点名 |
| "包含范围"漏掉绑定装饰 | 装饰部分被排除，目标破碎 | 视觉绑定 = 包含 |
| "排除范围"用"等"字 | 模型猜不到全部 | 逐项点名 |
| 不写锚点 | 比例 / 姿态走样 | 必给中心 + 关键锚点 |
| 字段单位不一致 | 模型比例错 | `width/height` 与 `整幅画布` 一致（像素） |
