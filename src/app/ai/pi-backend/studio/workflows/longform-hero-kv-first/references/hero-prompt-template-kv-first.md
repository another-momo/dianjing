# Hero 生图 prompt 构造

写候选 prompt 前读本篇。

## 三段拼装

每个候选 prompt = **风格定调 + 参照用法 + 文字禁令**。

### 风格定调

根据 CP1 锁定的方向写短句：视觉方向/风格词 2–4 个 + 构图机位 + 色彩氛围 + 单一主语 + 环境要素。不堆元素。

### 参照用法（必备，缺则图必坏）

围绕标题构图、标题区平静低细节、画面不画文字——三句是最小集：

- 「围绕本参考帧中标题版式所在位置安排主体，标题区周围保持平静」
- 「标题覆盖区域为低细节、低对比、单一色调的连续带，无物体、无图案、无边缘」
- 「画面中不出现任何文字、字符、符号、记号、标签」

### 文字禁令（必带）

> The image must contain no text, no lettering, no characters, no symbols, no logos, no watermarks, no marks of any kind.

与参照用法段的「标题区平静低细节」描述联合使用。

## 候选变异纪律

- 生成多个候选 prompt 时，每次只改一个方面（构图、氛围、题材选一），其他保持不变，才能对比出哪个因素影响了效果。
- 风格词与标题参照一批内不变。

## 回图诊断

| 症状              | 检测                | 动作                                       |
| ----------------- | ------------------- | ------------------------------------------ |
| 图内出现文字      | look 候选节点       | 重生，强化「不画字」+ 标题区「平静低细节」 |
| 标题区被主体盖住  | look 根框/hero 区   | 重生，强化「围绕标题构图」                 |
| 比例不符 scaffold | describe 报宽度不符 | 容器裁剪承裁，不拉伸                       |
| 风格漂出 CP1      | 与 CP1 对比         | 重生，风格词首句重述锁定方向               |
