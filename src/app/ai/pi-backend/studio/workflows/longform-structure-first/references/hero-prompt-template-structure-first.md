# Hero 生图 prompt 构造

写候选 prompt 前读本篇。

## 三段拼装

每个候选 prompt = **风格定调 + 参照用法 + 文字禁令**。

### 风格定调

根据 CP1 锁定的方向写短句：视觉方向/风格词 2–4 个 + 构图机位 + 色彩氛围 + 单一主语 + 环境要素。不堆元素。

### 参照用法（必备，缺则图必坏）

参考图 = scaffold 合成渲染图，图中已渲染真实标题文字（最终位置与字号）。生图模型不知道「标题区」在哪里——必须把它锚定到参考图中可见的文字块上，四句是最小集：

- **锚定**（定义标题区）：「参考图中渲染的文字即最终标题的位置与范围标记，其覆盖的矩形区域即标题区」
- **方位量化**（不让模型靠推断）：把标题区方位写成显式位置 + 占比，从 hero 槽实际版式推得——如 lower-third 版式写「参考图下部约三分之一处横贯一道标题文字带」
- **平静带**：「标题区（参考图中文字覆盖的矩形及其外沿一圈）保持为低细节、低对比、单一色调的连续带，无物体、无图案、无边缘穿过；主体围绕标题区安排，不侵占」
- **文字仅标记**：「参考图中的文字仅作位置标记——画面中不出现任何文字、字符、符号、记号、标签」

### 文字禁令（必带）

> The image must contain no text, no lettering, no characters, no symbols, no logos, no watermarks, no marks of any kind.

与参照用法段的平静带描述联合使用。

## 候选变异纪律

- 生成多个候选 prompt 时，每次只改一个方面（构图、氛围、题材选一），其他保持不变，才能对比出哪个因素影响了效果。
- 风格词与标题参照一批内不变。

## 回图诊断

| 症状                                     | 检测                   | 动作                                           |
| ---------------------------------------- | ---------------------- | ---------------------------------------------- |
| 图内出现文字                             | look 候选节点          | 重生，强化「参考图文字仅作位置标记」+ 文字禁令 |
| 平静带错位（低细节区偏离参考图文字位置） | look 候选叠比 scaffold | 重生，锚定句 + 方位量化写死位置与占比          |
| 标题区被主体盖住                         | look 根框/hero 区      | 重生，强化「围绕标题区构图、主体不侵占」       |
| 比例不符 scaffold                        | describe 报宽度不符    | 容器裁剪承裁，不拉伸                           |
| 风格漂出 CP1                             | 与 CP1 对比            | 重生，风格词首句重述锁定方向                   |
